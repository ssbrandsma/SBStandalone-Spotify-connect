# Spotify Connect 0.7.0

Released 14 November 2026 for Squeezebox Radio (`baby`) and Touch (`fab4`).
Both targets use the shared static ARMv5TE soft-float runtime with Linux 2.6
compatibility wrappers.

Changes:

- Natural track completion waits for the stock decoder and audio output to
  drain. Manual selection and next/previous cancel the wait immediately.
- The corrected 0.7.0 rebuild latches the firmware's STMu audio-completed
  event, so its temporary status flag cannot be missed between watcher ticks.
  Automatic advancement was confirmed working by the user on the Radio.
- Empty mobile selection URIs no longer override a valid track UID.
- Native Now Playing detects metadata arriving after stream-ready and sends
  updates queued during heartbeats.
- Process checks on the 250 ms Jive watcher read PID files and `/proc` directly,
  removing synchronous shell launches from the normal playback polling path.
- Disabled, Manual and Always On service modes, supervised recovery, and native
  StandaloneBase Now Playing integration are included in the release.
- Removed the obsolete custom Now Playing screen, artwork downloader and DNS
  helper. StandaloneBase handles artwork through its native display pipeline.

Validation: 32 Python/Lua tests, three Rust mobile-selection tests, native ARM
build for both targets, and the bridge EOS/manual-skip integration test passed.
The user confirmed the display integration works after device testing on
`192.168.1.78`. This release does not claim gapless playback or accurate speaker-
clock synchronization with Spotify's position display.
